# 🚀 QA Automation Framework (Java / Selenide / REST Assured)

Это демонстрационный проект (портфолио) для автоматизации e2e сценариев. Фреймворк включает в себя UI и API тесты, построен с использованием современных паттернов проектирования и интегрирован с CI/CD для непрерывного прогона тестов.

## 🛠 Стек технологий
* **Язык:** Java 17
* **UI Тесты:** Selenide (Selenium WebDriver)
* **API Тесты:** REST Assured + Jackson
* **Тестовый фреймворк:** JUnit 5
* **Генерация данных:** DataFaker
* **Отчеты:** Allure Report
* **CI/CD:** GitHub Actions + GitHub Pages
* **Сборщик:** Maven

## 🏗 Архитектура и паттерны
* **Page Object Model (POM):** UI-слой изолирован от тестов. Страницы инкапсулируют локаторы и методы взаимодействия.
* **API Clients:** Выделенный слой для работы с API (настройка спецификаций, отправка запросов и десериализация ответов в Java Record классы).
* **Data-Driven Approach:** Использование DataFaker для генерации уникальных тестовых данных в runtime.
* **Умные ожидания:** Использование встроенных механизмов Selenide для обработки динамических элементов.

## 💻 Запуск локально

**Предварительные требования:** Установленные Java 17 и Maven.

1. Склонируйте репозиторий:
```ruby
  git clone https://github.com/ivanT1625/e2e-automation-portfolio.git
```

2. Запустите все тесты:
```ruby
  mvn clean test
```

3. Сгенерируйте и откройте Allure-отчет:
```ruby
  mvn allure:serve
```

## ☁️ CI/CD и Отчеты
В проекте настроен пайплайн **GitHub Actions**. При каждом пуше в ветку `main` автоматически:
1. Поднимается Ubuntu-контейнер с Java 17.
2. Выполняется прогон тестов (UI тесты запускаются в Headless-режиме).
3. Генерируется Allure-отчет.
4. Отчет деплоится на GitHub Pages.

📊 **[Посмотреть актуальный Allure Report](https://ivanT1625.github.io/e2e-automation-portfolio/)** *(замените ссылку на свою из Settings -> Pages)*
